# nikori soda — DX PLUS

「ニコリヒト」がメロンクリームソーダを持って応援する、ブラウザ用アーケードゲームです。

## プレイ方法
[ゲームを開く](./index.html)（GitHub Pages 等で配信する場合に利用できます）。ローカルでは `index.html` をブラウザで開いてください。

- **W / S**：バー左端を上下に移動
- **↑ / ↓**：バー右端を上下に移動
- **スマートフォン**：画面内のタッチ操作を使用

## 収録機能
- クラシック（番号付きターゲット）、タイムアタック、エンドレス、復活チャレンジ練習
- 復活チャレンジ EXTREME（専用の縦スクロール盤面）
- ニコリヒトのCanvasコード描画・アニメーション
- メロンクリームソーダと泡の演出、オリジナルのポップな効果音・メロディー
- 設定、操作ガイド、実績、端末内ランキング、リザルト

## 技術・データ
外部の画像・音声ファイルを必要としない単体HTMLです。進行記録や設定などの保存にはブラウザのローカルストレージを使用します。ブラウザや端末が変わると記録は共有されません。

## 開発上の注意
原作『Ice Cold Beer』の操作方式を参考にした独立作品です。300個の穴を含む復活コースの実操作による通し攻略と、実機での音質・タッチ操作の検証は今後の確認事項です。
